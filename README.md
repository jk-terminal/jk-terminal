# jk-terminal

Learning Linux administration, bash scripting, networking and security. I build things in a home lab and write down what happened: what I set up, what broke, and what I changed.

Site: <https://jk-terminal.github.io>

## Focus areas

- **Linux administration:** running and maintaining my own Fedora system (packages, services, users, logs, updates)
- **Bash scripting:** small scripts that replace tasks I used to do by hand
- **Networking:** subnetting, VLANs and ACLs, extending into host and network firewalls
- **Security:** hardening my own devices and network first, with certification study alongside

## Currently learning

- bash scripting: variables, quoting, functions, exit codes
- git and GitHub: daily workflow, branches, publishing a site
- Next: firewalld zones and rules, system hardening, a segmented home lab network
